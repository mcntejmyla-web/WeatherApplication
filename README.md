# Weather Application 🌤️

A Java desktop weather application built using Java Swing and the OpenWeather API.

## Features

- Search weather by city
- Display current temperature
- Display weather conditions
- Display humidity
- Display wind speed
- 5-day weather forecast
- Weather alerts
- 10-minute weather data caching
- Clear cache functionality
- Network timeout handling
- Error handling
- User-friendly desktop GUI

## Technologies Used

- Java
- Java Swing
- OpenWeather API
- HTTP Client
- JSON data processing
- IntelliJ IDEA
- Git & GitHub
